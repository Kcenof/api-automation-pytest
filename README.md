Automated REST API Testing Framework

A fast and reliable automated API testing framework built with Python to validate backend functionality.

Tech Stack: Python, Requests, PyTest
Target API: JSONPlaceholder (Dummy REST API)

Features:

Validates HTTP status codes and API communication.

Verifies JSON response structures and data integrity.

Checks response data types and empty list handling.

How to run tests:
pytest tests/test_users_api.py -v -s
